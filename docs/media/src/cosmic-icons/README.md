# COSMIC icons used in the mockups

Copies of icons from System76's COSMIC icon theme ([pop-os/cosmic-icons](https://github.com/pop-os/cosmic-icons),
`/usr/share/icons/Cosmic/scalable/`), unchanged. `gen.py` embeds them in the Files mockup, so the
folders look as they do in COSMIC Files.
